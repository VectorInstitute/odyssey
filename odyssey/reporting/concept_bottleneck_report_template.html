Training & Evaluation Report

Concept-Bottleneck EHR Sequence Model

A Mamba-based clinical event forecaster trained with an interpretable concept bottleneck: known clinical concepts (SIRS, qSOFA, AKI staging, vital-sign thresholds) plus a residual unknown channel. This report covers the training run's loss trajectory, held-out quantitative evaluation, and several diverse patient case traces.

    Local-only. The case-trace section contains patient-level detail; PhysioNet's Data Use Agreement restricts sharing patient-level data outside credentialed access. Write this report only under a gitignored path (the builder's docstring says the same), never anywhere published.

    Observability

    Separately from getting a concept's value right, does the model know whether a concept will be measured at all for this patient? Scored against whether real data was ever observed for that concept, independent of the label's value.
